STEP 4
카카오톡 봇을 만들어 연동합니다

여러분이 만든 AI 에이전트가 고객들과 대화할 수 있도록, 카카오톡 봇을 연동해 주세요.

1
카카오디벨로퍼스

카카오디벨로퍼스에서 앱을 만들고, 그 앱 안에서 AI 에이전트를 생성합니다.

2
카카오톡 봇 연동

에이전트를 생성하면 카카오톡 봇에 연동해 주세요. 연동 방법은 하단의 [카카오톡 봇 연동 가이드]를 참고하세요.

3
App ID 확인

생성된 AI 에이전트의 App ID가 평가 대상 봇이 됩니다. 제출 단계에서 이 App ID를 입력해 제출해 주세요.

카카오톡 봇 연동 가이드

에이전트를 카카오톡 봇과 연동하려면 아래 절차대로 진행해 주세요.

카카오디벨로퍼스에서 앱 생성 후 챗봇 생성을 완료합니다.
발급된 인증 토큰을 확인하여 저장해 주세요.
REST API 문서 또는 튜토리얼을 참고하여 연동을 구현합니다.
카카오비즈니스 채널에서 자동 생성된 채널의 검색 허용과 채팅 기능을 꺼 주세요.
- 채널 > 채널 정보 > 옵션 설정 > 공개 설정에서 '검색 허용' 끄기 ('채널 공개'는 켜둔 상태로 유지)
