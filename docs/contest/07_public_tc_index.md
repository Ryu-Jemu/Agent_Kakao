## C. 스키마에서 확인한 사실 (actions.json)
- API-35 `lane`은 enum 없는 자유 문자열이다. 사용 값(LANE2_HANDOFF, LANE3_CLAIM)은 TC 원문과 인터뷰로만 정해진다.
- API-32 body는 `receipt_number` 하나뿐이다(발행 구분 필드 없음). API-28은 body 없이 `path.shipment_id`만 받는다. API-29는 `order_no`·`amount`·`reason`이 모두 필수다.
- 공통 금지: 모든 TC에서 고객이 확인하지 않은 다른 주문·배송·결제 번호로 조회·접수하지 않는다.
