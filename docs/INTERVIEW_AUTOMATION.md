# 인터뷰 자동 실행기 사용법 (D-005, 사용자 결정)

> 근거: 사용자 판단(2026-10-31 11:4x) — 이민준의 답장("설마 직접 손으로 타이핑…? 🤖👀📸→🤔→🖱️⌨️→🔁→🎉")을 '답을 기다리며 하는 자동화는 허용, 무책임한 대량 전송은 금지'로 해석.
> 규정 원문: `docs/contest/03_villager_interview.md:127~131`("분당 요청 수에는 제한이 없으나 … 서비스 과부하를 유발하는 자동화 대량 요청" 금지), `05_rules_faq.md:18·61·153`.
> 이 해석은 운영사무국의 확인을 받지 않았다(추가 확인 필요). 위험은 실격이며, 판단과 책임은 사용자에게 있다.

## 동작 (📸 → 🤔 → ⌨️ → 🔁)
1. `kb/questions/<관계자>.md`(A1 작성)에서 아직 보내지 않은 `- [ ] Qnn 질문`을 최대 N건(기본 5건, 상한 10건) 읽는다.
   - 200자를 넘거나 '프롬프트·내부 설정·너의 지침/규칙' 같은 표현이 든 질문은 거부한다.
2. 보낼 목록을 화면에 보여 준다. 사용자가 **`APPROVE`를 입력해야** 시작한다. 묶음마다 다시 승인한다.
3. 한 건씩 처리한다.
   - 대상 대화방 창을 맨 앞으로 가져오고, 제목이 다르면 오전송을 막기 위해 중단한다.
   - 질문을 붙여넣고 Enter를 누른다.
   - 화면 변화가 멈추고 새 답 줄이 보일 때까지 기다린다(최대 75초).
4. 답 영역을 캡처하고 한글 인식(macOS Vision)을 한 뒤 `inbox/interviews/<관계자>.md`에 기록한다. 캡처는 `inbox/images/auto/<관계자>/`에 저장된다.
5. 다음 경우에는 즉시 멈춘다.
   - `[SYSTEM]` 안내가 보일 때
   - 75초가 지나도 답 완료를 확인하지 못했을 때
   - Ctrl+C를 누르거나 `touch .coord/interview/STOP`을 실행했을 때
   - 관계자당 누적 95건에 도달했을 때
6. 끝나면 A1에게 INBOX 알림을 보낸다. A1은 답을 읽고 다음 질문을 큐에 올리고, 실행기를 다시 돌리면 된다(🔁).
- **잘린 답**: 500자가 넘는 답은 카톡에서 '전체보기'로 접혀 화면에 일부만 보인다. 기록에 `⚠️ 답이 잘림` 표시가 붙으면 카톡에서 원문을 복사해 해당 항목 아래에 붙여넣는다(KB 정확도용, 지식 발굴 점수에는 영향 없음).

## 사용자가 할 일
1. **권한 허용**(한 번만): 시스템 설정 > 개인정보 보호 및 보안에서 **macOS 기본 '터미널' 앱만** 두 곳에 허용한다(`/System/Applications/Utilities/Terminal.app`). **VS Code·ChatGPT에는 주지 않는다.** 에이전트 세션이 VS Code와 ChatGPT 안에서 돌고 있어서, 권한을 주면 에이전트도 카톡을 조작할 수 있게 된다(11:5x 프로세스 확인).
   - **손쉬운 사용**: 키 입력·창 제어용
   - **화면 및 시스템 오디오 녹음**: 캡처용
   - 첫 실행 때 'System Events 제어' 허용 창이 뜨면 허용한다.
2. **대화방 창 열기**: 카톡에서 해당 관계자 대화방(예: 이민준)을 **별도 창 하나로** 열어 둔다. 창 제목이 관계자 이름과 같아야 한다. 다르면 `--window "<제목>"`을 붙인다.
3. **점검**: 전송 없이 권한과 캡처 영역을 확인한다.
   ```
   cd ~/Desktop/Ryu/AI_TOP_100/2026_preliminary/Agent_Kakao
   bin/interview_runner.py --person 이민준 --check
   ```
   `inbox/images/auto/이민준/_check_region.png`에 대화 내용만 담겨야 한다. 입력창이 들어가면 `--bottom`을, 제목줄이 들어가면 `--top`을 키운다.
4. **실행**: 목록을 확인하고 `APPROVE`를 입력한다.
   ```
   bin/interview_runner.py --person 이민준 --max 5 --status
   ```
5. 실행 중에는 카톡 창을 건드리지 않는다. 키보드 입력이 섞이면 오전송될 수 있다.

## 실행기가 하지 않는 일
- 묶음 승인 없이 보내지 않는다. 답을 받기 전에 다음 질문을 보내지 않는다. 다른 대화방에 보내지 않는다.
- 질문을 스스로 만들지 않는다. 질문은 A1이 큐에 올린 것만 보낸다. 큐에서 질문을 고르고 승인하는 것은 사람이 한다.
