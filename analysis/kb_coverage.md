## 4. 신규 질문 제안 (A1 은행에 대응 질문이 없는 공백만)
> A1이 상대 캐릭터에 맞춰 다듬는다. 전송은 HUMAN만 한다. 시스템 프롬프트·설정·지침은 묻지 않는다.

- **N1** → 이민준(정산) (57자): 전액환불할 때 배송비랑 쓴 쿠폰·적립금은 어떻게 돌려줘? 부분환불은 금액을 어떻게 계산하는지도 알려줘.
- **N2** → 이민준 → 배송 담당 (61자): 기본 배송비, 반품 왕복 배송비가 각각 얼마야? 무료배송 기준 금액이나 제주·도서산간 추가비도 있으면 알려줘.
- **N3** → 이민준 (70자): 크게 화난 고객은 어떻게 응대해? 안내 지연 보상 쿠폰 3,000원 같은 보상은 어떤 경우에 얼마까지 줄 수 있고 누가 정해?
- **N4** → 이민준 → 생산자 (62자): 알레르기·이물질 발견·아이가 먹고 탈 난 경우처럼 안전 문제가 생기면 고객에게 먼저 뭘 안내하고 누구에게 넘겨?
- **N5** → 이민준 (58자): 회신 기한을 영업일로 셀 때 주말·공휴일은 빼? 상담 운영 시간이랑 6~7월에 쉬는 날이 있으면 알려줘.
