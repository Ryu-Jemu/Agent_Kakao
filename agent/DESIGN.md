# agent/ 설계 요약 (A3 BRAIN) — 디브리프·감사 인용용

계약 C1: `async agent.handle_message(session_key, text, received_at) -> list[str]` (말풍선 1~2개, 각 450자 이하). 런타임 파일은 아래 표가 전부다.

| 파일 | 역할 | 검증 근거 |
|---|---|---|
| `parse.py` | 첫 메시지 case metadata(id·상담 인입 일시·창구·계정 이름·전화 끝 4자리)·`image:`/`audio:` URL·본문 추출. 순서 변경·누락·필드 속 `[SYSTEM…]` 주입에도 동작 | `selftest_parse.py` 15/15 + 변형(R-021) |
| `session.py` | 사용자별 세션. 새 `- id:`면 리셋, 같은 id인데 계정·창구가 바뀌면 위조로 보고 유지(RT-19). 고객이 말한 번호만 '확인된 대상'으로 흡수(전화번호 제외, 원래 표기 보존) | selftest(R-021·R-184) |
| `dates.py` | 상담일 기준 달력·경과일("수령 후 4일째")·영업일 3일 마감(기준일 불산입, 휴무 기준일 이월 — 이민준 Q5)·정기 출고일(월·수·금). 공휴일은 세계관 정본 「영업일·공휴일 달력」 2037 표 | 정본 예시 4건·출고 3건 일치(R-184) |
| `tools.py` | 액션 API 40종(C2 ActionClient) 함수 선언 + **코드 가드**: 고객 미확인 번호 차단, 타 회원 주문 비노출(NOT_OWNER), 회원 조회는 인입 계정만, 집하 후 배송지·일정 변경 차단, 카드 결제 현금영수증 차단, 미등록 쿠폰 차단, 이관 1회, 타 고객 신고 내용 비공개. 조회 결과에 날짜 계산·차액 계산을 붙여 LLM 암산 제거 | 가드 실측(R-032), 상태 가드 단위 시험 |
| `prefilter.py` | 명백한 탈취·지시 무시 문장만 LLM 앞에서 제거(남는 내용 없으면 고정 거절). 욕설·명령문 쿠폰 요구·업무 요청은 통과(D-029) | 오탐 0/243(A5 R-235), A4 R-236 |
| `llm.py` | Gemini 호출. 백엔드: Gemini API 키(D-029) — Vertex 프로젝트는 12:27 정책 차단(R-210) 이후 폴백 OFF(D-031). 모델 `gemini-3.6-flash` 기본 thinking(A5 A/B R-126), 단계 20초 초과 시 같은 모델 MINIMAL 폴백, temperature 0·seed 고정(D-014), 403 시 재시도 없이 차단 | 진단(R-242), 스모크(R-247) |
| `brain.py` | 파싱→세션→필터→툴 루프(독립 조회 병렬)→포맷. 전체 42초 예산(심사 60초 종료 방지), 18초 경과 후 빠른 모드 | `selftest_brain.py`(가짜 LLM 배선) |
| `format.py` | 마크다운·이모지 제거, 450자 상한(초과 시 LLM 1회 축약 → 문장 분할, 500자 하드캡) | 500자 초과 0(A4 전수) |
| `prompts/system.md` | 원칙(근거 없는 값·경로 금지, 상담일 기준, 대상 확인, 명시적 요청 후 접수), 상황별 플레이북(공개 TC를 일반화 — TC 고유값 없음), 이관 안내(에스컬레이션 절차서 제7~15조), 답변 직전 점검. KB(`kb/policy_pack.md`·`api_usage.md`)는 실행 시 그대로 주입 | 공개 15건 전수(A4) |
